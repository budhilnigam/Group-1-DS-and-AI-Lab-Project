👋 Welcome to PR Code Review Bot

Automated code review system powered by LLMs and retrieval-augmented generation (RAG). Analyze GitHub PRs with multiple review strategies.

Getting Started:

  • Dashboard - View PR analytics, violation trends, and review metrics
  • Schedule - Monitor scheduled repos and their review activity log
  • Custom Inference - Run ad-hoc reviews on any PR using RAG, Naive LLM, or Static analysis
  • Evaluation - Test review accuracy against ground truth or batch evaluate multiple entries
  • Configuration - Manage repositories, custom rules, and prompts

Pro Tips: Configure your GitHub token and GROQ API key in the Configuration tab for full functionality.

JSON Batch Evaluation Format

Paste a JSON array in the code box. Each entry is evaluated independently against all 3 baselines. Ground truth rows on the right are ignored in this mode.

Provide code via source_file (path relative to data/processed/) or source_code (inline).

[
  {
    "id": "synthetic-django_PR_21",
    "repo": "kannan-dedsec/synthetic-django",
    "source_path": "admin.py",
    "source_file": "evaluation_files/synthetic-django_PR_21_admin.py",
    "ground_truth_reviews": [
      {
        "line_number": 9,
        "violation_category": "unused_import",
        "review_comment": "Unused import: os"
      }
    ]
  },
  {
    "id": "inline_example",
    "repo": "my-org/my-repo",
    "source_path": "app.py",
    "source_code": "import os\nimport sys\nx = 1\n",
    "ground_truth_reviews": [
      {
        "line_number": 1,
        "violation_category": "unused_import",
        "review_comment": "Unused import: os"
      }
    ]
  }
]
